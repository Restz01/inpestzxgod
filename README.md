# INPESTZ Bio Link

A glowing black-and-white bio-link page: 3D starfield + shader nebula/black hole, glass buttons,
custom cursor, TH/EN toggle, background music and sound effects. Plain static files, no build step.

## Files
- `index.html` - page structure and links
- `style.css` - look, effects, responsive layout
- `main.js` - WebGL background, effects, sound, music, language toggle
- `music.mp3` - background music (replace with a track you have the rights to use)

## Run locally
Open `index.html` in Chrome or Edge.

## Publish with GitHub Pages
1. Repo **Settings > Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`
3. Save, and the site goes live at `https://<username>.github.io/<repo>/`

## Edit
- Links: the `href` of each button in `index.html`
- Channel name: search `INPESTZ`
- Texts in Thai/English: the `I18N` object in `main.js`
